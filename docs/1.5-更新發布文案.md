日期：2026-11-28

1.5 的更新影片、封面和文案，都是簡體中文（B 站）。

## 檔案

| | 檔案 |
|---|---|
| 影片（50 秒，1080p60，有配樂） | `promo/out/FullWidget-1.5-update.music.mp4` |
| 封面 16:9（1920×1080） | `promo/out/update-1.5-cover-16x9.zh-CN.jpg` |
| 封面 4:3（1440×1080） | `promo/out/update-1.5-cover-4x3.zh-CN.jpg` |

- **影片**：版式和 1.3、1.4 一樣。章節依序是：
  1. 毛玻璃的問題：圓角固定、陰影關不掉、會壓暗旁邊的組件；
  2. 快照卡片：切換、調圓角、開關陰影、移動後重新截取；
  3. 陰影聽你的；
  4. 疊放順序不變（1.4 和 1.5 對比）；
  5. 右鍵選單更清爽。
- **封面**：版式和 1.4 一樣，左邊大標「1.5 更新了」、四個標籤和一句話。右邊是一個小桌面，上面一張快照卡片，下面是圓角和陰影的控制條。
- **重做**：
  - 影片：`node promo/render.mjs --page update-1.5-video.html --lang zh-CN --to 50 --out promo/out/FullWidget-1.5-update.mp4`，再跑 `node promo/update-1.5-music.mjs --mux`；
  - 封面：`node promo/render.mjs --cover update-1.5.html --lang zh-CN`。
- **發布前**：
  - 1.5.0 已在 GitHub 發布，軟體內更新會收到。
  - Microsoft Store 版還是 1.4.2，要先送審 1.5.0 的 Store 安裝包。上架之前，Store 用戶還收不到這次更新，影片結尾那句「已安装的会在软件里收到更新」對他們不成立。

### 简介

```
FullWidget 1.5 更新了。这次主要是卡片的样子：新加了“快照卡片”，阴影也终于听你的了。

▍下载：https://hmgvibe.github.io/FullWidget
▍源代码：https://github.com/hmgvibe/FullWidget
▍组件市场：https://hmgvibe.github.io/fullwidget-market

为什么做快照卡片：
以前的毛玻璃是 Windows 画的，圆角固定、阴影关不掉，几个组件挨在一起时，上面那个的阴影还会压暗下面那个。

这次更新：
・快照卡片（实验功能）：截一次组件后面的画面，模糊后当作卡片背景。圆角和阴影都由 FullWidget 画，圆角能调，阴影能关。背景不会自动更新，移动组件或换壁纸后，右键 → 重新截取背景。需要 Windows 10 2004 或更新版本
・阴影听你的：全局微调管所有组件；单个组件可以单独改，下次改全局时全部跟上。以前全局关掉阴影后，单个组件再打开也看不到阴影，现在修好了
・叠放顺序不变：点一下桌面空白处，组件之间的上下顺序不会再被打乱，旁边组件的阴影不会压暗它
・右键菜单更清爽：去掉了投影，只留一圈细边框

上个小版本 1.4.2 也修了几个问题：点击桌面层组件不再盖住其他窗口、单独选了主题的组件不受全局微调影响、回收站组件导致右键没反应、少数电脑上的闪退。

截取背景时，FullWidget 自己的窗口不会出现在截图里，截图只存在你的电脑上。

免费。开源（GPL-3.0）。没有账号、广告、统计。
```
