## 十分钟写第一个组件

我们来做一个“每日一句”：每天显示一句话，按一下换下一句，句子可以在控制中心改。

### 1. 创建组件（1 分钟）

1. 左键点托盘图标，打开控制中心。
2. 到控制中心“添加组件”页，按右上角的 **新建组件…**（窗口窄时只显示“＋”图标）。也可以右键系统匣图标 →“添加组件”→“新建组件…”。
3. 名称输入 `每日一句`，按 **创建**。

FullWidget 会：

- 在组件目录创建一个文件夹（例如 `%AppData%\FullWidget\widgets\my-widget`），里面是一个能用的模板；
- 把它放到桌面；
- 打开 **开发者模式**：之后改了文件夹里的文件，一存盘，桌面上的组件就会自动重新加载；
- 用文件总管打开这个文件夹。

用你习惯的编辑器打开这个文件夹。推荐 [VS Code](https://code.visualstudio.com/)：文件夹里的 `widget.d.ts` 会让它在你打 `widget.` 时列出所有可用的功能和说明。

### 2. 加一个设置项（1 分钟）

打开 `widget.json`，把 `settings` 整段换成：

```json
"settings": [
  { "key": "quotes", "type": "textarea", "label": "句子（一行一句）",
    "default": "慢慢来，比较快。\n今天也要好好吃饭。\n先完成，再完美。" }
]
```

存盘。打开控制中心 →“我的组件”→ 选“每日一句”→“内容”，会看到一个多行文字框，里面是这三句话。这个表单是 FullWidget 照 `settings` 自动生成的。

### 3. 写画面（3 分钟）

把 `index.html` 换成：

```html
<!doctype html>
<html>
<head>
  <meta charset="utf-8">
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <div class="w-label" id="day"></div>
  <p class="quote" id="quote"></p>
  <button class="w-btn" id="next">换一句</button>
  <script src="main.js"></script>
</body>
</html>
```

把 `style.css` 换成：

```css
body {
  display: flex;
  flex-direction: column;
  gap: 8px;
}

.quote {
  flex: 1;
  margin: 0;
  font-size: 1.3rem;
  line-height: 1.5;
}

#next {
  align-self: flex-end;
}
```

`<body>` 就是那张卡片。`w-label`、`w-btn` 是 FullWidget 自带的样式，背景、圆角、字体和颜色由主题提供，你不用写。

### 4. 写逻辑（3 分钟）

把 `main.js` 换成：

```js
const $ = (id) => document.getElementById(id);
let quotes = [];
let index = 0;

function show() {
  const quote = quotes.length ? quotes[index % quotes.length] : "到控制中心加几句话吧";
  $("quote").textContent = quote;
  $("day").textContent = new Date().toLocaleDateString(widget.locale, {
    month: "long", day: "numeric", weekday: "long",
  });
}

// 读设置：一行一句
function load(settings) {
  quotes = settings.quotes.split("\n").map((s) => s.trim()).filter(Boolean);
  show();
}

// 每天自动换一句；按过“换一句”的话，记住今天换到哪一句
const today = new Date().toDateString();
widget.storage.get("pick").then((pick) => {
  const dayNumber = Math.floor(Date.now() / 86400000);
  index = pick && pick.day === today ? pick.index : dayNumber;
  load(widget.settings.get());
});

// 用户在控制中心改了句子，马上更新
widget.settings.onChange(load);

$("next").addEventListener("click", () => {
  index++;
  widget.storage.set("pick", { day: today, index });
  show();
});
```

存盘，桌面上的组件马上变成新的样子。试试：

- 按“换一句”；
- 在控制中心改句子，桌面上实时更新；
- 到“主题”换一套主题，组件的字体和颜色会跟着变；
- 重新启动 FullWidget，今天换到的那一句还在（`widget.storage` 会一直保存）。

### 5. 出错了怎么办（1 分钟）

开发者模式下，脚本出错时卡片底部会出现一条红色提示，写着错误和位置（例如 `main.js:12`）。点一下它就会打开开发者工具；也可以在组件上按 **F12**。改好存盘，提示就会消失。

### 6. 分享出去（1 分钟）

控制中心 →“添加组件”→ 你的组件卡片 →“导出 .fwz”。别人双击这个 `.fwz` 文件就能安装（也可以拖到控制中心窗口上）。

想让所有人都能在控制中心的“在线”里找到它，可以投稿到[组件市场](https://hmgvibe.github.io/fullwidget-market/)：把组件文件夹放进 GitHub 上 [fullwidget-market](https://github.com/hmgvibe/fullwidget-market) 保存库的 `widgets/你的账号.组件名/`，开一个 pull request。自动检查通过、维护者看过后就会上架，详细步骤见那里的 CONTRIBUTING.md。

## 文件夹里有什么

| 文件 | 用途 |
|---|---|
| `widget.json` | 说明文件：名称、尺寸、权限、设置项。**必须有。** |
| `index.html` | 组件的页面（可以在 `widget.json` 的 `entry` 改成别的文件名）。 |
| `style.css`、`main.js` | 样式和逻辑。文件名随意，在 HTML 里用相对路径引用即可。 |
| `icon.svg` | 在组件库、托盘菜单和控制中心显示的图标（建议 24×24 的 SVG）。 |
| `widget.d.ts`、`jsconfig.json` | 只给编辑器用，让它提示 `widget.` 的写法。 |

组件目录：`%AppData%\FullWidget\widgets\`。在控制中心“设置”→“组件目录”可以直接打开。把一个组件文件夹放进去，它就会出现在“添加组件”里（开发者模式下自动出现，否则按“重新扫描”）。

文件请存成 **UTF-8**。

## widget.json

可以写 `//` 注释，最后一项后面多一个逗号也没关系。

```json
{
  "id": "me.daily-quote",
  "name": { "zh-TW": "每日一句", "zh-CN": "每日一句", "en": "Daily Quote" },
  "description": "每天一句话",
  "version": "1.0.0",
  "author": "你的名字",
  "entry": "index.html",
  "icon": "icon.svg",
  "category": "info",
  "size": {
    "width": 280, "height": 160,
    "minWidth": 200, "minHeight": 120, "maxWidth": 600, "maxHeight": 400,
    "resizable": true
  },
  "layer": "desktop",
  "permissions": [],
  "settings": []
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 唯一标识符。小写英文、数字和 `. _ -`，2–64 个字符，例如 `me.daily-quote`。之后不要改：保存的数据和更新都靠它。`fullwidget.` 开头的留给内置组件。 |
| `name` | 建议 | 显示的名称。可以是文字，也可以按语言给：`{ "zh-TW": "…", "en": "…" }`。 |
| `description` | | 一句话介绍，显示在组件库。同样可以按语言给。 |
| `version` | 建议 | 版本号，例如 `1.2.0`。安装 `.fwz` 时用它判断是更新、重新安装还是旧版本。 |
| `author` | | 作者。 |
| `entry` | | 页面文件，默认 `index.html`。 |
| `icon` | | 图标文件。没有的话显示名称的第一个字。 |
| `category` | | 在组件库里放在哪一类：`time`（时间）、`weather`（天气）、`system`（系统）、`productivity`（效率）、`info`（信息）、`media`（媒体与装饰）。不写或写别的，放在“其他”。 |
| `preview` | | 组件库卡片上的预览图，例如 `"preview.png"`。可以按主题和语言各放一张：`"preview/{theme}.{lang}.webp"`，`{theme}` 换成主题 id（`instrument`、`type`、`paper`），`{lang}` 换成 `zh-TW`、`zh-CN` 或 `en`；缺的那张会用同主题的其他语言，或其他主题代替。图片建议用透明背景的 PNG 或 WebP，宽 300 像素左右。没有的话卡片显示图标。 |
| `size` | | 卡片尺寸（不含阴影），单位是像素。`width`/`height` 是第一次放上桌面的大小；`min*`/`max*` 限制用户拖动缩放的范围；`resizable: false` 不让缩放；`grow`（0–1）决定用户把卡片拉得比默认大时，内容要不要跟着放大，见[放大时内容跟着变大](#放大时内容跟着变大)。 |
| `layer` | | 第一次放上桌面时的层级：`desktop`（默认，在所有窗口下面，Win+D 也看得到）、`normal`、`top`（置顶）。用户之后可以改。 |
| `permissions` | | 要用到的权限，见[权限](#权限)。 |
| `settings` | | 设置项。控制中心会照这里自动生成表单。 |

### settings：设置项

每一项：

```json
{
  "key": "city",
  "type": "text",
  "label": "城市",
  "description": "留空就自动定位",
  "default": ""
}
```

| 字段 | 说明 |
|---|---|
| `key` | 程序里用的名字：`widget.settings.get("city")`。 |
| `type` | 见下表。 |
| `label` | 表单上的名称。可以按语言给。 |
| `description` | 名称下面的一行小字说明。 |
| `default` | 默认值。任何类型都可以按语言给，例如 `{ "zh-TW": "google", "zh-CN": "baidu", "en": "google" }`。 |
| `placeholder` | 输入框里的提示文字。 |
| `min` `max` `step` | `number` 和 `slider` 用。 |
| `options` | `select` 用：`[{ "value": "c", "label": "摄氏" }, { "value": "f", "label": "华氏" }]`。 |

| type | 表单 | 值 |
|---|---|---|
| `toggle` | 开关 | `true` / `false` |
| `text` | 单行文字 | 字符串 |
| `textarea` | 多行文字 | 字符串（换行是 `\n`） |
| `number` | 数字框 | 数字 |
| `slider` | 滑杆 | 数字 |
| `select` | 下拉菜单（三个以内的短选项会显示成分段按钮） | 选项的 `value` |
| `color` | 颜色 | `"#rrggbb"` |
| `font` | 字体（可从系统字体中选） | 字体名称；用户清空时是 `null`（通常就用主题的字体） |
| `date` | 日期 | `"2026-12-31"` |
| `folder` | 文件夹（显示路径和“选择…”按钮） | 完整路径；默认值可以写环境变量，例如 `"%USERPROFILE%\\Pictures"`。见 [`widget.files`](#读取用户选的文件夹widgetfiles) |

## JavaScript API

FullWidget 会在你的脚本运行前准备好全局的 `widget`，不用 import。完整的类型和说明在 `widget.d.ts`。

需要等待的功能（读写数据、连网等）都回传 Promise，可以用 `await`。

### 基本数据

```js
widget.id          // "me.daily-quote"
widget.instanceId  // 桌面上这一个的标识符（同一个组件可以放几个）
widget.locale      // 用户的语言，例如 "zh-TW"，格式化日期和数字用
widget.theme       // 目前的主题："instrument"、"type"、"paper"
widget.developer   // 是否在开发者模式
widget.permissions // 现在能用的权限

// 按用户的语言挑文字
widget.t({ "zh-TW": "早安", "zh-CN": "早安", en: "Good morning" })
```

### 设置：`widget.settings`

```js
// 读设置：同步的，不用 await
const all = widget.settings.get();         // { quotes: "…", … }
const one = widget.settings.get("quotes");

// 用户在控制中心改了设置
widget.settings.onChange((all) => { /* … */ });

// 程序也可以改，控制中心会同步显示
await widget.settings.set("quotes", "…");
```

### 保存数据：`widget.storage`

保存的东西重开电脑也在；用户移除这个组件时一起删除。桌面上每一个组件各有自己的一份。上限每个 2 MB。

```js
// 可以存任何 JSON 数据
await widget.storage.set("todo", [{ text: "买牛奶", done: false }]);

// 没存过的是 null
const todo = (await widget.storage.get("todo")) || [];

await widget.storage.remove("todo");
const keys = await widget.storage.keys();
```

### 系统信息：`widget.system`（需要 `system` 权限）

```js
const stop = widget.system.subscribe(["cpu", "memory"], (d) => {
  cpu.textContent = Math.round(d.cpu.usage) + "%";
  mem.textContent = Math.round(d.memory.usage) + "%";
}, { interval: 2000 });  // 每 2 秒一次，默认 1 秒；第一笔会马上到

stop(); // 不需要时停止
```

| 主题 | 内容 |
|---|---|
| `cpu` | `usage`（%）、`cores` |
| `memory` | `usage`（%）、`total`、`used`、`available`（字节） |
| `network` | `down`、`up`（每秒字节）、`totalDown`、`totalUp` |
| `disk` | 每个磁盘一项（含U盘）：`name`（"C:"）、`label`、`type`（`fixed` / `removable`）、`total`、`free`、`usage`（%） |
| `battery` | `present`、`percent`、`charging`、`pluggedIn`、`secondsLeft`、`saver`（省电模式） |

多个组件订阅同一个数据时，FullWidget 只采样一次，不会多耗资源。

不常变的数据用一次性的调用：

```js
const pc = await widget.system.info();
// pc.os.name "Windows 11 Pro"、pc.os.version "25H2"、pc.cpu.name、pc.memory.installed（字节）、
// pc.gpus（显卡名称）、pc.computer（电脑名称）、pc.uptime（已开机的毫秒数）

const net = await widget.system.adapters();
// net.online；net.adapters[0] 是连上网络的那个：name "Wi-Fi"、type "wifi"、ipv4、gateways、dns

const r = await widget.system.ping("1.1.1.1");   // { ok, ms, status }；每个组件每秒最多一次
```

### 音量：`widget.audio`（需要 `audio` 权限）

```js
const stop = widget.audio.onChange((a) => {
  // a.volume 0–100、a.muted、a.device（"喇叭 (Realtek Audio)"）
  // 按键盘的音量键、任务栏调音量、换成耳机时都会马上通知
});
await widget.audio.set({ volume: 40 });
await widget.audio.set({ muted: true });
```

### 正在播放：`widget.media`（需要 `media` 权限）

读取 Windows 媒体控制里正在播放的内容（Spotify、浏览器、媒体播放器……，和音量面板上看到的一样），并控制它：

```js
widget.media.onChange((m) => {
  if (!m.available) return;          // 没有程序在播放
  // m.title、m.artist、m.album、m.app.name（"Spotify"）、m.app.icon
  // m.playing、m.position、m.duration（毫秒）、m.cover（封面图片的网址，可直接放进 <img>）
  // m.can.next、m.can.previous、m.can.seek：那个程序现在接受哪些按钮
});
const now = widget.media.position(m);   // 现在播到哪里（播放中会自己往前走）
await widget.media.toggle();            // 播放 / 暂停；也有 play()、pause()、next()、previous()
await widget.media.seek(60000);         // 跳到 1:00
// 目前这首歌的时间轴歌词，在网易云音乐、QQ 音乐、酷狗上查找
const { title, lyrics } = await widget.media.lyrics();
if (lyrics.found) lyrics.lines;         // [{ t: 毫秒, text, tr?: 翻译 }]，按时间排好
```

Windows 有变化时会马上通知（换歌、暂停、换了一个程序在播放），不用自己轮询。

### 读取用户选的文件夹：`widget.files`

在设置项里放一个 `folder` 类型的设置，用户选了文件夹，组件就能读取里面的图片。**选文件夹本身就是允许**，不用在 `permissions` 声明：

```json
{ "key": "folder", "type": "folder", "label": "照片文件夹", "default": "%USERPROFILE%\\Pictures" }
```

```js
const { files } = await widget.files.list("folder", { recursive: true });
// files: [{ path: "2025/海边.jpg", name: "海边", size, modified, url }]
img.src = widget.files.url(files[0], { width: 800 });   // Windows 做的缩小版，大照片也很快、很省内存
const { taken } = await widget.files.info("folder", files[0]);  // 拍摄时间（相机记录的），没有时是 null
await widget.files.pick("folder");      // 在组件里直接打开选文件夹的窗口，选好后存进设置
```

- 只能读那个文件夹（和里面的子文件夹）里的图片：jpg、png、gif、webp、bmp、avif、heic、tif，最多 5000 张。
- 别人写的组件，`default` 里写的文件夹不算数，要等用户自己选过才能读。内置组件和自己写的组件可以用默认值。
- 文件夹的设置值里可以写环境变量，例如 `%USERPROFILE%`。

### 连网：`widget.fetch`（需要 `network:` 权限）

和浏览器的 `fetch` 很像，但由 FullWidget 代为发送，所以不受 CORS 限制：

```js
const r = await widget.fetch(
  "https://api.open-meteo.com/v1/forecast?latitude=25&longitude=121&current=temperature_2m"
);
if (r.ok) {
  const data = await r.json();
}

await widget.fetch("https://example.com/api", {
  method: "POST",
  headers: { "content-type": "application/json" },
  body: { hello: "world" },   // 对象会自动转成 JSON
});
```

回应有 `ok`、`status`、`statusText`、`url`、`headers`、`body`（文字）、`text()`、`json()`。图片等二进位内容用 `{ as: "base64" }`，`body` 就是 base64 文字。每次最多 8 MB，会自动跟随转址（每一跳都要在权限内）。

### 打开网址：`widget.shell.open`（需要 `shell.open` 权限）

```js
// 用默认浏览器打开；也接受 mailto:
widget.shell.open("https://example.com");
```

组件页面本身不能跳转到别的网址，也不能开新窗口；要打开网页请用这个。

### 打开程序和文件：`widget.shell.launch`（需要 `shell.launch` 权限）

```js
await widget.shell.launch("C:\\Windows\\notepad.exe");    // 程序、快捷方式、文件夹、文档都可以；不能带参数

const path = await widget.shell.pick({ type: "file", filter: "programs" }); // 让用户选；取消时是 null
const info = await widget.shell.info(path);  // { name: "记事本", kind: "app", icon: "data:image/png;…" }

// 文件拖到组件上时取得完整路径
document.addEventListener("dragover", (e) => e.preventDefault());
document.addEventListener("drop", async (e) => {
  e.preventDefault();
  const paths = await widget.shell.paths(e.dataTransfer.files);
});
```

`pick` 的 `type` 可以是 `file` 或 `folder`，`filter` 可以是 `programs`、`images` 或 `all`。

### 运行命令：`widget.shell.run`（需要 `shell.run` 权限）

在这台电脑上运行命令，拿回它印出来的内容。FullWidget 还没有的功能，很多用一行 PowerShell 就做得到。**只有你自己写的组件能用**：安装包和组件市场里的组件要这个权限会被拒绝。

```js
const r = await widget.shell.run("Get-Date -Format HH:mm");   // 默认用 PowerShell
// r = { code: 0, ok: true, stdout: "21:30\r\n", stderr: "", timedOut: false, truncated: false }

await widget.shell.run("dir /b", { shell: "cmd", cwd: "C:\\Users" });
await widget.shell.run("$input | Sort-Object", { input: "b\na\nc" }); // input 从标准输入送进去，每行一项
await widget.shell.exec("git", ["-C", "D:\\code", "status", "--short"]);  // 直接运行程序，不经过 shell

// 定时更新：跟 setInterval 一起用
setInterval(async () => {
  const r = await widget.shell.run("(Get-CimInstance Win32_Battery).EstimatedChargeRemaining");
  show(r.stdout.trim());
}, 60_000);
```

- 命令在后台运行，不会跳出窗口；默认在组件自己的文件夹里运行。
- `timeout` 默认 30 秒，最长 10 分钟，时间到就结束它（`timedOut: true`）。组件关掉时，它启动的命令也会一起结束。
- 输出的编码：PowerShell 和 `exec` 默认是 UTF-8，`cmd` 默认是 `oem`（中文 Windows 是 GBK 或 Big5）。旧的命令行程序印出乱码时，加上 `encoding: "oem"`。
- 命令失败不会让 promise 失败：看 `ok` 和 `code`，错误消息在 `stderr`。
- 一直开着、会主动送数据回来的事，例如监听某个软件的状态，用[插件](#插件)比较合适。

### 简繁转换：`widget.convertChinese`

```js
await widget.convertChinese("北极熊和幼崽", "traditional");  // "北极熊和幼崽"
```

用 Windows 内置的字表逐字转换，适合短句（例如网上取得的简体标题），不处理“软件 / 軟體”这类用词差异。不需要权限。

### 通知：`widget.notify`（需要 `notify` 权限）

```js
// 马上弹出一则 Windows 通知（标题默认是组件名称）
widget.notify("下载完成");

// 预约在某个时间；同一个 tag 的新预约会取代旧的
widget.notify({ title: "番茄钟", body: "休息一下", at: Date.now() + 25 * 60 * 1000, tag: "end" });

widget.notify.cancel("end"); // 取消这个预约；不给 tag 就取消这个组件的全部预约
```

预约由 FullWidget 计时，所以就算组件因为全屏幕或“隐藏全部组件”暂停了，通知也会准时出现。最多预约 7 天以内、每个组件 20 则；电脑睡眠醒来时，迟了超过 15 分钟的预约不再显示。

### 窗口：`widget.window`

```js
const { width, height } = await widget.window.getSize();
await widget.window.setSize(320, 200);   // 会被限制在 size 的 min/max 之内
```

### 外观和事件

```js
// 目前的主题和外观值
widget.appearance.get();

// 换主题或改外观时（CSS 变量已经更新好了）
widget.appearance.onChange((a) => {});

// 锁定、层级、鼠标穿透改变时：{ locked, layer, clickThrough }
widget.on("state", (s) => {});

// 被快捷键叫出来时（目前是便签和待办清单的快捷键，叫出 fullwidget.notes、fullwidget.todo）：把光标放进主要的输入框
widget.on("summon", () => {});

// 写进 FullWidget 的日志
widget.log("消息", { any: "data" });
```

## 外观：跟着主题走

FullWidget 有几套主题，用户也能在控制中心调整背景、文字颜色、强调色、字体、字号、圆角、内边距和透明度。只要你的组件用下面这些变量和样式，这一切都会自动生效。

### 布局

- `<body>` 就是卡片：背景、圆角、边框、内边距都已经设好。内容直接放进 `<body>`。
- `<html>` 是透明的窗口，四周留了给阴影的空白，不要给它加背景。
- 字号用 `rem`：用户调“字号”时，`1rem` 会跟着变（默认 14px）。
- 卡片可能被缩放。用 flex/grid 排版；要按大小调整，可以在 `body` 上设 `container-type: size`，再用 `@container (max-height: 100px) { … }`。注意 `@container` 只能改 `body` 里面的元素，改不了 `body` 本身。

### 放大时内容跟着变大

在 `widget.json` 的 `size` 加上 `"grow": 1`，用户把卡片拉得比默认大时，整张卡片的内容会一起放大，字、图标、间距都按比例变大，不会只是多出空白：

```json
"size": { "width": 260, "height": 150, "minWidth": 180, "minHeight": 110, "grow": 1 }
```

- 放大的倍数是“宽放大几倍”和“高放大几倍”中较小的那个，最多 3 倍。例如拉到两倍宽、1.3 倍高，内容放大 1.3 倍，多出来的宽度交给你的排版。
- 比默认小时不会缩小，小尺寸要靠你自己的排版（上面的 `@container`）。
- `grow` 可以是 0 到 1 之间：清单类的组件写 `0.5`，拉大时字变大一点，同时多显示几项。
- 不写或写 `0`：和以前一样，只是多出空间。
- 卡片的圆角、边框和阴影不会跟着放大。目前的倍数在 CSS 变量 `--w-size-scale`。

### CSS 变量

| 变量 | 用途 |
|---|---|
| `--w-fg` | 主要文字颜色 |
| `--w-fg-muted` | 次要文字（标签、说明） |
| `--w-fg-faint` | 很淡的文字、分隔 |
| `--w-accent` | 强调色：进度、选中、重点数字 |
| `--w-on-accent` | 放在强调色上面的文字 |
| `--w-warn` `--w-danger` | 警告、危险 |
| `--w-bg` | 卡片背景（已用在 body 上） |
| `--w-bg-solid` | 卡片的颜色，但不透明：用在要挡住后面内容的地方，例如弹出的清单 |
| `--w-border` `--w-rule` | 边框、分隔线 |
| `--w-track` | 进度条的底 |
| `--w-control-bg` `--w-hover` | 输入框底色、滑过时的底色 |
| `--w-font` | 内文字体 |
| `--w-font-num` | 数字的字体 |
| `--w-font-display` | 组件里那个最大的数字（时间、温度）的字体 |
| `--w-font-title` | 标题字体 |
| `--w-radius` `--w-padding` | 卡片圆角、内边距 |

### 现成的样式

| class | 用途 |
|---|---|
| `w-label` | 小号、次要颜色的标签文字 |
| `w-title` | 标题 |
| `w-num` | 数字（等宽、主题的数字字体） |
| `w-display` | 最大的那个数字 |
| `w-rule` | 分隔线（用在 `<hr>` 或 `<div>`） |
| `w-bar` | 进度条：`<div class="w-bar"><i style="width:40%"></i></div>`；加 `is-warn` 变成警告色 |

| `w-btn` | 按钮；加 `is-primary` 变成强调色按钮 |
| `w-check` | 圆形勾选框：`<button class="w-check" aria-pressed="true">` |

### 按主题微调

`<html>` 上有这些属性，可以写专门的样式：

```css
/* 某一套主题 */
html[data-theme="paper"] .quote { font-style: italic; }

/* 用户选了毛玻璃卡片（data-style 是 transparent、frosted 或 snapshot：快照，实验功能） */
html[data-style="frosted"] .quote { letter-spacing: 0.02em; }

/* 组件被锁定时 */
html[data-locked="true"] #next { display: none; }
```

用户也可以在控制中心“外观 → 自订 CSS”给单一组件加样式，它会排在你的 CSS 之后。

### 省电：每秒更新的东西不要加动画

组件整天开着，每一帧画面都要算。每秒更新一次的数字或进度条，如果加了 0.5 秒的 `transition`，画面就几乎一直在动，一个组件可以吃掉 20% 的处理器内核；不加的话只要 1%。

- 每秒或更频繁更新的元素，不要 `transition` 和 `animation`。`w-bar` 默认有 0.5 秒的宽度动画，每秒更新时写 `.w-bar > i { transition: none; }`。
- 不要 `animation: … infinite`；要闪烁提示，给一个次数（例如 `8`）。
- 指针、转盘这类要转的东西，放在独立的元素上用 CSS `transform` 转，不要每秒重画整个 SVG。
- 每分钟才变的东西，就每分钟才更新（`setTimeout` 对准下一分钟）。

## 拖动、菜单和点击

FullWidget 已经帮你处理好：

- **拖动**：在卡片任何地方按住拖动，就能移动组件。按钮、链接、输入框不会触发拖动；其他元素不想被拖动时，加上 `data-no-drag`。
- **右键**：显示 FullWidget 的组件菜单。某个区域要自己处理右键时，加上 `data-no-menu`。
- **缩放**：`size.resizable` 不是 `false` 时，右下角会有缩放手把。
- **锁定**：用户锁定组件后不能拖动和缩放；你可以用 `widget.locked` 和 `html[data-locked]` 知道。

## 权限

组件默认只能显示自己的内容：不能连网、读不到系统信息、也碰不到你电脑上的文件。要用到这些，在 `widget.json` 的 `permissions` 里声明：

| 权限 | 允许 |
|---|---|
| `system` | `widget.system`：处理器、内存、网速、磁盘、电池 |
| `network:api.example.com` | 连到这个网站 |
| `network:*.example.com` | 连到 example.com 和它所有的子网域 |
| `network:*` | 连到任何网站（用户安装时会看到明显的提示，能不用就不用） |
| `shell.open` | `widget.shell.open`：用浏览器打开网址 |
| `notify` | `widget.notify`：显示 Windows 通知 |
| `audio` | `widget.audio`：读取和调整系统音量、静音 |
| `media` | `widget.media`：读取正在播放的歌名、封面，播放、暂停、切换曲目 |
| `shell.launch` | `widget.shell.launch`、`pick`、`info`、`paths`：打开程序和文件、选文件、读取名称和图标（用户允许时会看到明显的提示） |
| `shell.run` | `widget.shell.run`、`exec`：在这台电脑上运行命令（只给你自己写的组件） |
| `plugin:名称` | `widget.plugin("名称")`：使用你的插件（只给你自己写的组件）；官方插件 `plugin:fullwidget.*` 谁都能用。见[插件](#插件) |

读取文件夹不用声明权限：用户在设置里选了哪个文件夹，组件就只能读那个文件夹里的图片，见 [`widget.files`](#读取用户选的文件夹widgetfiles)。

**谁来允许：**

- 用“新建组件”创建的组件是你自己写的，声明的权限直接生效。
- 别人的组件，安装时会列出它要的权限，用户按“安装”才算允许。更新后多要了权限，用户要再允许一次，在那之前新权限用不了。
- 把别人的组件文件夹直接放进组件目录的话，第一次放上桌面时会先请用户允许。
- `shell.run` 和 `plugin:` 能做的事没有边界，只给你自己写的组件：要这两种权限的安装包（.fwz）会被拒绝，组件市场也不收。例外是 FullWidget 的官方插件（`plugin:fullwidget.*`）：市场上的组件也可以用，安装时用户会看到。

**连网的规则：** 不只 `widget.fetch`，页面里直接加载的图片、字体、脚本、`fetch()` 和 WebSocket 也只能连到允许的网站。差别是：直接 `fetch()` 要对方网站支持 CORS，`widget.fetch` 不用。

## 插件

FullWidget 还做不到的事，不用等更新：写一个插件。插件是你自己写、自己用的小程序，用什么语言都可以（PowerShell、Python、Node、C#…）。你的组件把请求交给它，它做完把结果交回来；它也可以随时主动送数据给组件。你自己写的插件不会上组件市场，也不能放进安装包；市场上只有 FullWidget 的[官方插件](#官方插件)。

**完整说明在[插件开发指南](插件开发指南.md)**：协议的每个细节、Python／Node.js／PowerShell／C# 的完整示例、调试和常见错误。它写得可以整份交给 AI，让 AI 帮你写插件。这一章是摘要。

**创建：** 控制中心 →“设置”→“插件”→“新建插件”。会在插件文件夹（数据位置里的 `plugins`）创建一个能运行的 PowerShell 示例，打开文件夹，并且直接允许它。

```
plugins\
  hello\
    plugin.json    说明怎样启动它
    main.ps1       插件本身
```

**plugin.json：**

```json
{
  "name": "Hello",
  "description": "这个插件做什么",
  "run": "main.ps1",
  "idleMinutes": 5
}
```

- `run`：怎样启动它，在插件文件夹里运行。只写脚本文件名时，`.ps1` 用 PowerShell、`.py` 用 `python`、`.js` 用 `node`、`.bat`/`.cmd` 用 cmd 运行；也可以写完整的命令，例如 `"python -u main.py --port 4455"` 或 `"bin\\tool.exe"`。
- `idleMinutes`：没有组件在用多少分钟后让它停下，默认 5；`0` 表示一直开着，直到 FullWidget 结束。

**通信方式：** FullWidget 往插件的标准输入每行送一个 JSON 请求，插件从标准输出每行回一个 JSON（UTF-8）：

```
→ {"id": 1, "method": "hello", "params": {"name": "小明"}, "widget": "user.my-widget"}
← {"id": 1, "result": "你好，小明"}
← {"id": 2, "error": "找不到这个文件"}               失败时回 error，组件那边的 promise 会失败
← {"event": "changed", "data": {"scene": "Live"}}   随时都可以送，听这个插件的组件都会收到
```

- 标准输出只能写这种 JSON 行。给自己看的消息写到**标准错误**（stderr），会记进 `app.log`。
- 每写完一行要 flush，不然 FullWidget 收不到（Python 已经设好 `PYTHONUNBUFFERED`）。
- 标准输入被关掉（读到结尾）就表示该结束了，3 秒内没结束会被强制结束。
- 环境变量 `FULLWIDGET_PLUGIN`、`FULLWIDGET_VERSION`、`FULLWIDGET_LANG` 告诉它自己的名字、FullWidget 的版本和界面语言。
- 用 Windows PowerShell 5.1 写的话，用 `[Console]::OpenStandardInput()` 读输入（示例就是这样），`[Console]::In` 等输入时会卡住整个插件。

**在组件里用：** 先在 `widget.json` 声明 `"permissions": ["plugin:hello"]`，然后：

```js
const hello = widget.plugin("hello");
const text = await hello.call("hello", { name: "小明" });        // 等它回 result
const off = hello.on("changed", (data) => render(data));         // 收它送来的事件；off() 停止
await hello.call("slow", null, { timeout: 120_000 });            // 默认等 30 秒，最长 10 分钟
```

Python 写的插件大概是这样：

```python
import json, sys
for line in sys.stdin:                      # 读到结尾：FullWidget 要我们结束
    req = json.loads(line)
    if req["method"] == "hello":
        out = {"id": req["id"], "result": f"你好，{req['params']['name']}"}
    else:
        out = {"id": req["id"], "error": f"没有方法 {req['method']}"}
    print(json.dumps(out, ensure_ascii=False), flush=True)
```

**什么时候运行：** 组件第一次用到它时启动，没有组件用它 `idleMinutes` 分钟后停下。它自己结束了，而还有组件在听它的事件，FullWidget 会等一下再启动它；3 分钟内停了 5 次就不再重开，修好后在“设置 → 插件”按“重新启动”。改了插件文件夹里的文件，运行中的插件会自动重新启动。FullWidget 结束时，插件和它启动的程序都会一起结束。

### 官方插件

组件市场有一个“官方插件”专栏，只放 FullWidget 自己做的插件：名称都是 `fullwidget.` 开头，源代码在[组件市场的 plugins 文件夹](https://github.com/hmgvibe/fullwidget-market/tree/main/plugins)公开，不接受投稿。在控制中心“添加组件 → 在线 → 官方插件”安装和更新，装好就是允许的。

投稿到市场的组件可以用官方插件：在 `permissions` 声明 `"plugin:fullwidget.perf"`，用法和自己的插件一样。用户装你的组件时，如果还没有那个插件，控制中心会提示他安装。插件不在的时候 `call` 会失败（消息含 `no plugin`），请在组件里告诉用户去哪里装。

| 官方插件 | 提供 |
|---|---|
| `fullwidget.perf` 性能数据 | 每秒的事件 `stats`：显卡使用率、显存、温度、功耗、频率，和每个在绘制画面的软件的帧率。方法：`stats`、`info`、`enableFps`。说明见它的 [README](https://github.com/hmgvibe/fullwidget-market/tree/main/plugins/fullwidget.perf) |
| `fullwidget.files` 文件 | 用户用插件的窗口选了文件夹之后，列出里面的文件和图标，打开、在资源管理器显示、拖出去、把文件放进来、改名、新建文件夹、删到回收站，有变化时送出事件 `changed`。只能碰用户选的文件夹。见它的 [README](https://github.com/hmgvibe/fullwidget-market/tree/main/plugins/fullwidget.files) |

**安全：** 插件用你的身份运行，能做你在这台电脑上能做的任何事。所以：

- 插件要在“设置 → 插件”里允许之后才会运行，允许时会列出它要运行的命令。“新建插件”创建的会直接允许。
- `plugin.json` 改过之后要再允许一次（改插件的代码不用）。
- 只有你自己写的组件能用插件。别人叫你把某个文件夹放进 `plugins` 的话，先看清楚它在做什么。

## 调试

在控制中心“设置”打开 **开发者模式**（用“新建组件”时会自动打开）。打开后：

- **存盘即重新加载**：组件文件夹里任何文件存盘后，用到它的组件会自动重新加载；改了 `widget.json`，新的尺寸和设置项也会立即生效。
- **错误提示**：脚本出错时，卡片底部会显示错误和位置，点一下打开开发者工具。
- **开发者工具**：在组件上按 F12，或控制中心“我的组件 → 位置与行为 → 开发者工具”。F5 重新加载。
- **日志**：`widget.log()` 的内容和组件的错误，都写在 `%LocalAppData%\FullWidget\logs\app.log`。
- **没有加载的组件**：`widget.json` 写错（例如少了逗号、id 不合规则、找不到入口文件），“添加组件”页顶部会列出是哪个文件夹、哪一行、什么问题。

**命令行**（在终端运行，作用在正在运行的 FullWidget 上）：

```bat
FullWidget.exe --cmd="reload me.daily-quote"
FullWidget.exe --cmd="devtools me.daily-quote"
FullWidget.exe --cmd="add me.daily-quote"
FullWidget.exe --cmd="rescan"
FullWidget.exe --cmd="export me.daily-quote D:\out\daily-quote.fwz"
FullWidget.exe D:\downloads\daily-quote.fwz
```

`reload`、`devtools` 也可以用桌面上某一个的标识符（控制中心“位置与行为”里的“标识符”）。

## 打包和分享

`.fwz` 就是把组件文件夹压成 zip、改了扩展名。

- **导出**：控制中心“添加组件”→ 你的组件卡片 →“导出 .fwz”。隐藏的文件和文件夹（例如 `.git`）以及 `node_modules` 不会被打包。
- **安装**：双击 `.fwz` 文件、把它拖到控制中心窗口上，或在“添加组件”按“安装 .fwz 文件…”。安装前会显示名称、作者、版本和需要的权限。
- **更新**：改大 `version` 再导出。`id` 相同的组件会被替换，桌面上的组件、设置和保存的数据都会保留；旧版本移到资源回收筒。
- **用框架写**：React、Vue、Svelte 都可以，只要输出静态文件。把建置结果（例如 `dist/`）和 `widget.json` 放在一起，`entry` 指向它的 `index.html`；资源路径要用相对路径（例如 Vite 设 `base: "./"`）。
- **大小限制**：`.fwz` 最大 64 MB，解压后最多 256 MB、5000 个文件。

## 常见问题

**改了文件，桌面上没变化。**
确认“设置”里开发者模式是开的。没开的话，在组件上右键 →“重新加载”。如果改的是 `widget.json` 而组件不见了，看“添加组件”页顶部是不是列出了错误。

**`widget.fetch` 失败，说 permission denied。**
把那个网站加进 `permissions`，例如 `"network:api.example.com"`。错误消息里会写出要加的那一行。如果说 "not allowed yet"，表示已经声明但用户还没允许：到控制中心“我的组件”选这个组件，按“查看并允许”。

**直接用 `fetch()` 或 `<img>` 加载网络上的东西失败。**
网站要在 `permissions` 里。`fetch()` 还要对方支持 CORS；不支持的话改用 `widget.fetch`。

**中文变成乱码。**
把文件存成 UTF-8。

**想让组件第一次出现时大一点或小一点。**
改 `size.width` 和 `size.height`。已经在桌面上的组件会保留用户调过的大小，可以从“添加组件”再放一个新的来看效果。

**怎样让组件在浅色主题（纸本）下也好看？**
文字和线条都用 `--w-*` 变量，不要写死白色或黑色。到控制中心“主题”切换三套主题看一遍。
