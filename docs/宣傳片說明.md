# 宣傳片 — 說明

日期：2026-11-03

## 結果

60 秒的 FullWidget 宣傳片做好了：

- **規格**：16:9、1920×1080、60fps，沒有聲音，轉場卡在 120 BPM 的節拍上。
- **做法**：整支片是一個 HTML 頁面（`promo/`），在瀏覽器裏可以播放、拖時間軸。`node promo/render.mjs` 會逐幀錄成 MP4，輸出到 `promo/out/FullWidget-promo.mp4`（不進 git）。
- **風格**：跟官網一樣。暖白頁面和深色段硬切，組件放在 logo 四色派生的小桌布上，薄荷色強調，緩動曲線也用官網和控制中心的那兩條。
- **鏡頭**：照蘋果宣傳片的做法，整支片是一個連續的鏡頭，上一段的東西直接變成下一段的主角。

計劃在 `docs/宣傳片計劃.md`，怎麼預覽、怎麼錄、配樂對照表在 `promo/README.md`。

## 做法

**時間軸**
- 每一幀都是時間 t 的純函數，沒有自己跑的動畫和計時器（`promo/engine.js`）。
- 所以在瀏覽器裏可以隨意拖時間，錄影時每一幀都準確。同一個時間點不管先錄哪些幀，結果都一樣（已驗證）。

**組件**
- **大部分**：用官網的 2 倍真實渲染圖。
- **桌面上的時鐘**：是真正的時鐘組件，經官網的 `site/widget-host.js` 在 iframe 裏跑，時間固定 9:41。
  - 換主題時是組件自己重新上色，不是換圖。
  - 瀑布流裏那一格和結尾的時鐘，用同一個組件拍的 9:41 圖（`render.mjs --assets`），所以鑽進去時時間不會跳。
- **組件市場兩個組件**：用 `make-previews.mjs --from market/widgets --scale 2` 拍 2 倍圖，放在 `promo/assets/market/`。

**改動到的現有檔案**
- `site/widget-host.js`：加兩個選項：
  - `root`：組件資料夾的位置。
  - `head`：放進組件 `<head>` 的額外內容，這裏用來固定時間、關掉組件內部的過場動畫。
  - 預設行為不變，官網不受影響。
- 刪除舊的 `docs/宣傳視頻企劃.md`（照你說的不用了）。
- `.gitignore`：加上 `promo/out/`（錄影輸出）和 `.tools/`（ffmpeg）。

**錄影**
- `promo/render.mjs`，不用 npm 套件：
  1. 內建靜態伺服器。
  2. 開幾個無頭 Edge 平行逐幀截圖。
  3. 每段交給 ffmpeg 編碼，最後接起來：H.264、CRF 15、BT.709、yuv420p，可以在網頁快速開播。
- **ffmpeg**：從 gyan.dev（ffmpeg.org 官方下載頁推薦）下載 9.0.2 essentials 版，核對過 SHA-256。解壓在 `.tools/ffmpeg/`，沒有安裝到系統。

## 檢查中修掉的問題

| 問題 | 怎麼修 |
|---|---|
| 瀑布流的時鐘圖是官網拍的「00:22」，鑽進去後變成「09:41」 | 自己拍 9:41 的時鐘圖，所有時鐘都用它 |
| 寫組件那段左邊露出其他組件的碎片 | 鏡頭推近，只框住日曆和新組件 |
| 安裝後，控制中心裏的小「早安」和權限單殘留在之後的畫面上 | 隱藏的圖層裏，子元素若被設為「顯示」會透出來；改用透明度，並在隱藏時重設 |
| 結尾切場那一幀是空白 | 結尾的卡片改成切過來時就在 |
| 26–28 秒畫面完全靜止 | 桌面在中段加一個很慢的推近 |
| 主題切換時桌布閃一下 | 交叉淡化的起點對齊節拍 |
| 吸附虛線的邊緣在不同次錄影中有細微差異 | 虛線改畫在螢幕座標並對齊整像素 |
| 第一次錄影卡住近 2 小時：這台電腦的 Edge 會自動裝上 AdGuard 擴充，它的歡迎分頁把錄影分頁擠到背景，背景分頁不畫畫面 | 錄影時關閉擴充、自動關掉多出來的分頁並把錄影分頁放在前面；單幀超過 15 秒會重試 |
| 35.25–37 秒程式碼打完後完全靜止 1.75 秒（ffmpeg 靜止偵測抓到） | 這一段也加上很慢的推近 |

## 驗收

- **靜態圖**：每段抽 2–3 張逐張看過；整支片每 0.5 秒一幀拼成縮圖表（`render.mjs --sheet 0:60:0.5`），確認沒有跳幀和空白。
- **可重現**：同一個時間點錄兩次，以及把 11 個時間點打亂順序錄、和逐一單獨錄比較，結果完全一樣（像素差 0；只有幾幀有 ≤3/255 的反鋸齒差異）。
- **MP4**：
  - 檔案 `promo/out/FullWidget-promo.mp4`，23.4 MB。
  - ffprobe 確認：H.264 High、1920×1080、60fps、yuv420p/BT.709、3600 幀、60.000 秒。
  - 4 個 Edge 平行錄影，3.6 分鐘。
  - 從 MP4 本身抽幀檢查畫面正確。
  - 用 ffmpeg 的靜止偵測掃過整支片：沒有超過 1.2 秒完全不動的地方。

## 沒驗證

- **動效順不順**：我只能看靜態幀，60fps 播起來的手感要你看。
- **音樂**：沒有配樂；配一首 120 BPM 的音樂，第一拍對齊 0 秒（對照表在 `promo/README.md`）。
- **其他語言**：字幕只做了繁中。文字都在 `promo/copy.js`，組件圖也有簡中和英文版，要出其他語言時再換。
- **組件市場**：影片裏有「線上安裝」，發佈影片前要先把市場倉庫公開。
