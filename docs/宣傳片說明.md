# 宣傳片 — 說明

日期：2026-11-03（第二版：快剪，加上配樂；配樂第二版）

## 結果

宣傳片改成快剪版：

- **規格**：74 秒、16:9、1920×1080、60fps，有配樂。
- **節奏**：每 1–3 秒一個鏡頭，切點卡在 120 BPM 的節拍上。
- **動起來的不只是轉場，還有組件本身**：時鐘在走、番茄鐘在倒數、CPU 和網速曲線在跳、計算機在按、待辦在打勾。
- **三種語言**：繁中、簡中、英文各一支。`node promo/render.mjs --lang zh-TW|zh-CN|en` 逐幀錄成 `promo/out/FullWidget-promo.<語言>.mp4`（不進 git）。
- **配樂**：用程式寫的原創曲子，`node promo/music.mjs --mux` 合成並加進影片，成品是 `promo/out/FullWidget-promo.<語言>.music.mp4`。
- 怎麼預覽、怎麼錄、每個切點在第幾秒第幾拍，都在 `promo/README.md`。

## 三種語言

- **怎麼切換**：所有文字在 `promo/copy.js`，繁中、簡中、英文各一份；網址加 `?lang=zh-CN` 或 `?lang=en` 就換語言。
- **跟着換的不只字幕**：
  - 真組件用該語言跑（日期、按鈕、待辦內容、音樂名稱）。
  - 組件截圖用官網該語言的版本，9:41 的時鐘圖每種語言各拍一張。
  - 簡中的中文字型換成微軟雅黑。
- **名稱有根據**：組件名照各組件的 `widget.json`，主題名照官網，控制中心和權限視窗的字照程式的翻譯。
- **英文字比較長**：分類大標縮小、兩欄間距拉開；全螢幕的副標和「0.4%」那行改短，避免超出畫面。

## 內容有根據

- **全螢幕**：照程式的說明寫「隱藏並停止更新」。
- **CPU 約 0.4%、記憶體約 355 MB**：M9 實測（38 個組件放在桌面上，Windows 11）。
- **每類組件的數量和名稱**：照官網的組件清單。
- **組件市場**：只出現真的兩個組件（護眼提醒、每日一句）；自己寫的「CPU 小卡」標成「審核中」。
- **畫面裏的系統數字和音樂**：是編出來的示意數據。

## 做法

- **真組件**：`promo/live.js` 讓真的組件在影片裏跑：
  - 在組件的 iframe 裏換掉 `Date`、`setTimeout`、`setInterval`、`requestAnimationFrame`，由影片的時間推進，而且可以加速。
  - 系統數據和媒體狀態由它模擬。
  - 打勾、按計算機這些操作，在指定時間點模擬點擊。
- **`site/widget-host.js` 新增的選項**：
  - `storage`：給定的初始資料，只放在記憶體。
  - `calls`：額外的模擬呼叫。
  - `send`：推送事件給組件。
  - 設定的預設值如果分語言（例如待辦的標題），會照語言選好。
  - 官網原本的用法不受影響。
- **鏡頭的隱藏方式**：鏡頭用 `display:none` 隱藏，不會再發生第一版那種「隱藏的圖層裏有東西透出來」的問題。
- **錄影**：同第一版：無頭 Edge 逐幀截圖，ffmpeg 編成 H.264。

## 配樂

- **第二版**：第一版（電子風、Dmaj9 這類加了延伸音的和弦）旋律和和弦不好聽，改成拍手踏腳的明亮流行風。
- **原創，不是模仿某首歌**：只學這類產品影片的風格，曲子和音色都是自己寫的。
- **編制**：踏地、一群人拍手、鈴鼓、沙鈴、兩把木吉他、撥弦低音、馬林巴、鐘琴，口哨吹主旋律。
- **和弦和旋律**：主歌 D → A → Bm → G，全是簡單的三和弦；口哨旋律一個音一個音寫好，同一個動機出現三次，最後收回主音。
- **全部用程式合成**：`promo/music.mjs`。吉他和低音用撥弦模型（Karplus–Strong），比上一版的合成器音色更像真樂器。不用取樣，也不裝套件。
- **跟着畫面走**：
  - 切點有風聲和鈴鼓，點擊、吸附（彈手指）、打勾、打字各有聲音。
  - 全螢幕那幾秒整首歌被悶住，組件回來時才打開。
  - 寫組件那段只剩吉他、彈手指和打字聲，卡片活起來時全團回來。
  - 深色那段三下重擊，接着指彈吉他，最後全團回來，收在 D 和弦上。
- **音量**：−14.0 LUFS，峰值 −1.3 dBTP，符合線上影片平台的標準（約 −14 LUFS、−1 dBTP）。
- 細節見 `promo/README.md` 的「配樂」。

## 驗收

- **畫面檢查**：每個鏡頭都抽了靜態圖檢查，整支片每 0.5 秒一幀拼成縮圖表看連續性。
- **修掉的問題**：
  - 大字被飛過的組件擋住：組件改從字的外圍飛出，字後面加淡光。
  - 有些組件被面板底邊切掉、待辦留白太多。
  - 打包那一幕的 CPU 卡片蓋到天氣組件。
  - 主題名稱蓋到媒體組件。
  - 每個鏡頭開頭的幾幀太空：入場提早到切點就開始。
- **MP4**：見最後一節。
- **配樂**：
  - 用波形圖和頻譜圖檢查各段的大小聲；頻譜圖上看得到口哨旋律在 13、45、66 秒進來。
  - 程式印出各聲部的響度，照着調：口哨最上面，吉他其次，馬林巴在前奏走到前面，深色那段讓指彈吉他出來。
  - 合成後的 MP4 有畫面和聲音兩軌，都是 74 秒。
