# 官網 — 說明

日期：2026-11-03

## 結果

做了 FullWidget 的官網，原始碼在 `site/`，三種語言（繁中、簡中、英文），桌面和手機都能看。已上線：<https://hmgvibe.github.io/FullWidget/>（2026-11-03 開啟 GitHub Pages，來源是 GitHub Actions）。

本機預覽：

```
node site/build.mjs
```

會產生 `_site/`，用任何靜態伺服器打開 `_site/index.html`。`_site/` 不進 git。

## 頁面

1. **首屏**：
   - 大標「一個不一樣的 Windows 桌面小組件」，旁邊是下載鍵。
   - 下面是 38 個組件的瀑布流，每個組件放在一小塊自己的桌布上，五欄各自慢慢往下流。
   - 滑鼠移上去會暫停，也有「暫停」按鈕；系統設定了減少動態效果時，瀑布流不動。
2. **01 簡單上手**：一張桌面場景，用 1、2、3 標出三步：
   1. 雙擊 FullWidget.exe。
   2. 桌面上出現組件。
   3. 打開控制中心添加更多。
3. **02 深入自定義**：一個真的在跑的時鐘組件，往下捲時依次：
   1. 換三套主題，桌布跟着換。
   2. 調強調色、圓角、透明度，旁邊有外觀表單。
   3. 打出 CSS 並套用。
   4. 縮到一邊，露出它自己的程式碼（節錄自 `widgets/clock/main.js`）。

   往回捲會倒着變回去。手機上時鐘固定在上半部，下半部顯示目前這一步的說明。
4. **03 開源・放心**：
   - 主角是安裝第三方組件時的權限確認卡（用組件市場裏真的「護眼提醒」）。
   - 旁邊三點：沒有帳號、廣告、統計；GPL-3.0；記憶體（起步約 95 MB、每個組件 +4 MB、38 個全開實測約 355 MB）。
5. **下載**：
   - 完整版 52 MB 是主按鈕，精簡版 4 MB 註明要先裝 .NET 9。
   - 附 SmartScreen 兩個畫面的示意圖，標出要按「其他資訊」和「仍要執行」。
   - 程式簽章政策的連結。
6. **頁尾**：GitHub、開發文檔、隱私、GPL-3.0。（SignPath 簽章申請沒通過，2026-11-03 拿掉了簽章政策的連結。）

手機上按下載鍵會改成複製下載連結，並提示「這是 Windows 電腦軟件」。

## 怎麼做的

- **方向**：用 oil-ui 流程。
  - 先拆了 Seelen、Lively、Rainmeter、Raycast 的真實首屏，它們都是「深色底、居中標題、截圖」。這裏改用淺色頁面，讓組件自己的顏色當主角。
  - 第一版方向（可以拖動的桌面）你不要，改成現在的純介紹。
- **真的組件跑在網頁裏**：`site/widget-host.js` 在網頁裏扮演 FullWidget 主程式。時鐘的 HTML、CSS、JS 原封不動載入，主題、外觀和 CSS 的變化都走產品本身的接口。
- **組件圖片**：
  - `build/make-previews.mjs` 新增 `--scale 2 --out <資料夾>`，以 2 倍解析度重新渲染了全部 342 張（38 個組件 × 3 主題 × 3 語言），放在 `site/assets/widgets/`。
  - 渲染時組件放在螢幕外，不會在你的桌面上跳出來。
- **控制中心截圖**：`site/assets/app/`，三種語言，版本號 1.2.0。
- **動效庫**：Motion（MIT 授權，`site/vendor/`，自己託管）。沒用 GSAP，因為它的授權不是開源授權，會影響 SignPath 的申請。
- **不連第三方**：首頁不連任何第三方網站，字體用系統字體，動效庫也放在本站。
- **分享圖**：`site/assets/og.png`。
- **發佈流程**：`.github/workflows/site.yml`。改了 `site/`、組件或版本號，或發佈新 Release 時，自動重建並發佈到 GitHub Pages，網址會是 `https://hmgvibe.github.io/FullWidget/`。

## 順便修掉的：預覽圖裏有這台電腦的資料

- 「電腦資訊」「網路狀態」「磁碟」三個組件的預覽圖，原本拍到這台電腦的真實資料：
  - Windows 版本、i7-12700H、RTX 3060、螢幕解析度；
  - 區網 IP 192.168.1.110；
  - 磁碟名稱和容量。
- 這些圖也在已公開的倉庫裏。
- 現在 `build/previews.json` 給這三個組件換上虛構的數值（Core Ultra 7、192.168.0.23 等），官網和程式內的預覽圖都重拍了。
- 舊圖還留在 git 歷史裏（只有那一個提交），敏感度低。要徹底清掉得再改寫一次歷史。
