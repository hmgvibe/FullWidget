# 更名為 FullWidget

日期：2026-11-02

## 結果

軟件從 DeskWidgets 改名為 **FullWidget**，並換了新 logo。用舊版的人換成新版後，組件、設定和資料都會留着。

## 新 logo

![logo](../build/logo/logo-256.png)

三張組件卡片拼成字母 F，右下角的圓點把方塊補滿，取「Full」的意思。顏色沿用舊 logo 的四色。

- 原稿：`build/logo/logo.svg`（64 格）。
- `build/make-icon.ps1` 畫出 `app.ico` 的 9 個尺寸，並輸出 `build/logo/logo-16/32/256/512.png`。
  - 16、20、24 px 另外按像素對齊畫，系統匣和工作列上不會糊。
- 用到 logo 的地方：
  - exe 圖標、系統匣、控制中心和開發文檔的標題列：讀同一個 `app.ico`（嵌入在 exe 裏）。
  - 控制中心側邊欄、右鍵選單頂部、組件市場網站和 favicon：用同一份 SVG。

選的時候比較過三個方案：

| 方案 | 為甚麼沒選 |
|---|---|
| 滿格便當：大小不一的卡片填滿方塊 | 小尺寸時右下的時鐘糊成一團 |
| 滿環儀表：深色底板上一圈走滿的儀表 | 和名字的關係要靠解釋 |

## 改了甚麼

| 項目 | 舊 | 新 |
|---|---|---|
| 程式 | `DeskWidgets.exe` | `FullWidget.exe` |
| 原始碼 | `src/DeskWidgets/`、`DeskWidgets.sln` | `src/FullWidget/`、`FullWidget.sln` |
| 資料夾 | `%APPDATA%\DeskWidgets`、`%LOCALAPPDATA%\DeskWidgets` | `…\FullWidget` |
| 內建組件 id | `deskwidgets.clock` 等 | `fullwidget.clock` 等 |
| 組件包 | `.dwz` | `.fwz` |
| 環境變數 | `DESKWIDGETS_DEV_ROOT`、`DESKWIDGETS_MARKET`、`DESKWIDGETS_DRYRUN` | `FULLWIDGET_…` |
| SDK 路徑 | `/__dw/` | `/__fw/` |
| 組件市場 | `hmgvibe/deskwidgets-market` | `hmgvibe/fullwidget-market`（網址 `hmgvibe.github.io/fullwidget-market/`） |

文件、範本、組件市場的腳本和網站都一起改了。

## 舊版升級時

- **資料夾**：第一次啟動時，舊的 `DeskWidgets` 資料夾會整個改名為 `FullWidget`。新資料夾已經存在，或舊資料夾被佔用時，就不搬，舊資料不動。
- **組件 id**：設定檔裏的 `deskwidgets.*` 自動換成 `fullwidget.*`，桌面上的組件和已允許的權限都留着。
- **開機自動啟動**：舊的「DeskWidgets」啟動項會換成指向新 exe 的「FullWidget」。
- **檔案類型**：雙擊 `.fwz` 和舊的 `.dwz` 都會用 FullWidget 打開；舊的檔案類型登記會清掉。「安裝 .fwz 檔案…」的選檔視窗也接受 `.dwz`。
- **第三方組件**：寫着 `/__dw/places.js` 的組件照樣能用。
- **保留的 id**：`fullwidget.` 和 `deskwidgets.` 開頭的 id 都留給內建組件，第三方組件不能用。組件市場的自動檢查也一樣。

## 實機驗證

用測試資料夾（`--data-dir`）模擬舊版的設定檔：

- **組件 id**：設定裏寫 `deskwidgets.clock`、`deskwidgets.weather`，以及 `deskwidgets.weather` 的連網權限。
  - 啟動後變成 `fullwidget.*`，兩個組件正常顯示，權限還在。
  - 日誌記下「built-in widget ids renamed」。
- **SDK 路徑**：`/__fw/base.css` 和舊的 `/__dw/places.js` 都能讀到，不存在的檔案回 404。
- **舊組件包**：用命令列打開一個 `.dwz` → 控制中心出現安裝畫面，檔名顯示 `old.dwz`。
- **新 logo**：
  - 控制中心的標題列圖標和側邊欄都是新 logo。
  - 右鍵選單頂部是新 logo。
  - 組件市場網站的標題列是新 logo，下載的是 `.fwz`。
- **組件市場**：重新跑了自動檢查和打包。

## 沒驗證

- **舊資料夾搬家**和**開機啟動項改名**：只在真正的 `%APPDATA%` 和註冊表上才會發生。這台電腦沒有舊版的資料夾和啟動項，測試不改動你的系統，所以沒有實際跑過。
- **系統匣圖標**：只看了各尺寸的圖，沒有截系統匣（會拍到你的其他程式）。
- **組件內容**：各組件的預覽圖沒有重拍，內容沒有改動。
- **組件市場**：只在本機提交（`market/`），沒有建立 GitHub 儲存庫，也沒有推送。
