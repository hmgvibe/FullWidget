# FullWidget 競品分析

日期：2026-11-02　對象：FullWidget 1.1.0

## 結論

1. **重點：桌面組件軟體比的是「有多少人在幫它做組件」，不是內建幾個。** Rainmeter 十幾年都靠社群做的皮膚撐着，但它有兩個問題：寫皮膚要學它自己的 ini 格式；皮膚能直接執行任何命令，從網上下載別人的皮膚有風險。FullWidget 用 HTML/CSS/JS 寫組件，這是會的人最多的介面技術；組件又要先取得權限、彼此隔離。所以它是**第一個「任何前端開發者都能寫、任何人都能放心裝」的桌面組件平台**。
   - **另一半賣點是「不用折騰」**：大多數人不想找皮膚、改設定檔，打開就要能用。38 個內建組件、三套主題，一打開就有一套好看又實用的桌面。這點 Rainmeter 做不到：它裝好後幾乎是空的，好看的桌面要自己去找皮膚、一個個調。
   - 兩邊互相成就：不想折騰的人，靠內建組件一裝就滿意；想多要一點的人，有社群做的組件可以裝；會寫網頁的人，自己寫了還能分享出去。
   - 這樣看，線上組件庫不是「之後再做」的功能，是讓產品持續長出新內容的地方；內建組件的品質和開發者體驗（文檔、範本、熱重載、投稿流程）都要顧好。
   - 一句話定位：**「打開就好看，想要更多就自己寫：免費開源的 Windows 桌面組件。」**
2. **最大的差距不在功能，在分發和生態**：沒有線上組件市集、沒上架 Microsoft Store / winget、沒有程式碼簽章、沒有自動更新。Rainmeter、Wallpaper Engine、DeskDash 的護城河都是社群內容，不是程式本身。
3. **記憶體是唯一明顯的技術劣勢**：WebView2 起步約 95 MB，原生自繪的 Rainmeter、GadgetPack 低得多。要主動公開數字，並把「之後每個組件 +4 MB」講清楚。
4. **建議下一步**（按優先順序）：簽章 + 上架 winget/Store → 自動更新 → 線上組件庫（先做「官方精選 + 一鍵安裝 .fwz」）→ 測 Windows 10。

## 3. 我們的優勢

- **三種用戶一個產品**：同一個軟體同時照顧「點添加就好」「想調外觀」「想自己寫」三種人。競品通常只顧一種。
- **開發門檻最低**：前端開發者不用學新格式，十分鐘寫出一個組件；有 `.d.ts`、熱重載、DevTools、模板。Rainmeter 的 ini 格式是它最大的入門障礙。
- **安全模型比 Rainmeter 好**：權限寫在 `widget.json`、安裝時讓用戶確認、每個組件獨立來源和 CSP。Rainmeter 皮膚能直接跑命令，分享皮膚有風險。
- **內建內容完整**：38 個組件、三套主題、三種語言都看過一遍。BeWidgets、Uwidgets 只有幾個。
- **小、乾淨**：小 zip 約 4 MB，無帳號、無廣告、可便攜。對中文市場「免費但塞廣告、要會員」的產品是明顯差異。

## 4. 我們的劣勢

| 劣勢 | 影響 | 誰做得好 |
|---|---|---|
| 沒有線上組件庫，只能互傳 .fwz | 用戶看完 38 個就沒新東西；開發者寫了組件沒地方給人看 | Wallpaper Engine 創意工坊、DeskDash 市集、Rainmeter 社群 |
| 只有 zip，沒簽章 | 下載和第一次開啟會被 SmartScreen 擋，一般用戶會退縮；不容易被搜到 | BeWidgets、Widget Launcher（Store）、Rainmeter（winget） |
| 沒有自動更新 | 修了 bug 用戶收不到 | 幾乎所有競品 |
| 記憶體起步約 95 MB | 「輕量」是賣點之一，但會被拿來和 Rainmeter 比 | Rainmeter、GadgetPack |
| 小 zip 要另裝 .NET 9 | 多一步就少一批人 | Store 版競品都沒有這步 |
| Windows 10 沒測 | Win10 仍有不少用戶，懷舊 / 老電腦用戶尤其多 | Rainmeter、GadgetPack、BeWidgets |
| 沒有知名度 | 新產品通病 | — |

## 5. 威脅

- **微軟把小工具放回桌面**：2023 年就傳過。真推出的話，「只要時鐘天氣」的那群人會被吃掉。對策：我們的差異是自訂和自寫，不和系統比「有沒有天氣」。
- **Seelen UI 這類整套方案**：免費、做得廣，組件只是其中一塊。對策：在組件這一塊做得更深、更穩，並強調「只裝組件，不換掉工作列」。
- **WebView2 的記憶體印象**：如果被評測寫成「又一個網頁套殼」，輕量的定位就站不住。對策：公開實測數字，把共用渲染進程、全螢幕暫停、低資源模式寫在首頁。

## 6. 建議

**短期（下一個版本）**

1. **程式碼簽章 + winget**：成本低，直接解決 SmartScreen 和「搜不到」。之後再上 Microsoft Store（Store 版也順便解決 .NET 執行階段和更新）。
2. **自動檢查更新**：啟動時查 GitHub Releases 或自己的 JSON，有新版在控制中心提示。
3. **Windows 10 實測**：先確認能不能跑，再決定是否正式支援。
4. **公開資源數字**：在 README 和介紹頁放「幾個組件用多少記憶體」的表。

**中期**

5. **線上組件庫**：先做最簡單的版本：一個靜態 JSON 清單 + 官方精選組件，控制中心裏一鍵下載安裝 .fwz（沿用現有的權限確認）。之後再開放投稿、審核。
6. **主題分享**：主題比組件好做、好分享，是最容易長出社群內容的地方。
7. **佈局一鍵匯出匯入**：讓「我的桌面」能整套分享（截圖 + 檔案），對應 Rainmeter 社群最常見的分享方式。

**之後再考慮**

8. **收費方式**：核心免費；可考慮付費主題包或捐贈。不建議會員制或廣告，這正是和中文市場競品拉開差距的地方。
9. **匯入 Rainmeter 皮膚**：能把 Rainmeter 的內容量借過來，但格式複雜、工程量大，先不做。

## 7. 待補

- 中文市場（小智桌面等 Windows 版產品）的功能、收費、廣告情況，這次沒有查到可靠資料。
- DeskDash、Uwidgets、Seelen UI 的實際記憶體佔用，需要裝起來實測。
- 微軟「小工具釘到桌面」的最新狀態，要看 Windows Insider 部落格確認。
