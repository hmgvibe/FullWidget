## 資料位置

- 設定與組件數據：`%AppData%\FullWidget\`（`config.json`、`widgets\`、`storage\`）
- WebView2 快取與日誌：`%LocalAppData%\FullWidget\`（`logs\app.log`）
- 用 `--data-dir=路徑` 可指定其他資料夾（便攜模式、測試）

## 命令行

正在運行時，可以用第二次啟動來控制它：

```
FullWidget.exe --cmd="add fullwidget.clock"
FullWidget.exe --cmd="layer fullwidget.clock top"      (top | normal | desktop)
FullWidget.exe --cmd="style fullwidget.clock frosted"  (transparent | frosted)
FullWidget.exe --cmd="move fullwidget.clock 100 100"
FullWidget.exe --exit
```

其他命令：`remove`、`reload`、`lock <id> on|off`、`clickthrough <id> on|off`、`shadow <id> on|off`、
`size <id> 寬 高`、`lock-all`、`unlock-all`、`hide-all`、`show-all`、`rescan`、`devtools <id>`。
`<id>` 可以是實例 id，或組件 id（取第一個實例）。

## 實機測試結果

全部在本機（Win11 26300、150% 縮放）實際運行驗證：

- SDK 測試組件 15 項全部通過：設定讀寫與通知、存儲（含中文）、系統數據、
  允許的網絡請求成功、未聲明的域名和 `shell.open` 被拒絕、調整大小。
- 首次啟動自動建立預設佈局（時鐘 + 系統監控），兩者不重疊。
- 拖動、右下角縮放、鎖定後不能拖。
- 原生右鍵選單：深色、按 Esc 和點別處都能關閉，選項可正常執行。
- 透明和毛玻璃兩種外觀、滑鼠穿透開關。
- 桌面層：Win+D 後可見；點擊並打字時不會跳到其他視窗前面；中文輸入法可用。
- 重啟後位置、大小、層級、外觀、存儲數據全部恢復。
- 第二次啟動不會開出新進程。
- 3 個組件：約 137 MB（任務管理器），共用 1 個渲染進程。日誌沒有任何錯誤。

## 測試中修掉的問題

1. 預設的兩個組件疊在同一位置 → 找空位時改為檢查所有已登記的組件。
2. 部分組件的陰影留白區變成半透明深色 → CSS 會把 body 背景「提升」到整個視窗，已在 `base.css` 阻止。
3. WinForms 右鍵選單關不掉 → 改用 Windows 原生選單。
4. 桌面層組件被點擊後跳到最前 → 改為被啟用後立即放回桌面層。
