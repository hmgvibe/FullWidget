# FullWidget 宣傳視頻企劃

日期：2026-11-02　對象：FullWidget 1.1.0（免費、開源）

---

## 一、所有亮點

### 一打開就好看（給所有人）

1. **38 個內建組件**，分六類：
   - 時間：數字時鐘、指針時鐘、翻頁時鐘、世界時鐘、日曆、倒數日、番茄鐘、計時器、時間進度
   - 天氣：天氣、一週天氣、空氣品質、日出日落和月相
   - 系統：系統監控、使用曲線、網速、磁碟、電池、網路狀態、電腦資訊、資源回收筒、音量、電源
   - 效率：便利貼、待辦清單、快捷啟動、習慣打卡、計算機、搜尋框
   - 資訊：自訂資訊卡、新聞訂閱、匯率、每日圖片、歷史上的今天
   - 媒體與裝飾：媒體控制、相框、白噪音、文字標籤
2. **三套很不一樣的主題**，一鍵切換：
   - **量被畫出來**：石墨玻璃配薄荷綠，每個數字都畫成看得見的量
   - **玻璃上的字**：沒有卡片，字直接浮在桌布上
   - **書桌上的紙**：米白紙、墨色、朱紅印章，像書桌上的紙製文具
3. **第一次打開就有預設佈局**（時鐘、天氣、系統監控），不用設定。
4. **繁中、簡中、英文**，跟着 Windows 語言走。簡中預設用大陸連得上的資料來源。

### 想怎麼擺就怎麼擺

5. **拖動自動吸附**：靠近邊緣或其他組件時自動對齊，保持 12 px 間距；按住 Ctrl 自由擺放。
6. **排列模式**：所有組件顯示虛線外框、名稱和尺寸，一次排好。
7. **三種層級**：置頂、普通、桌面層（按 Win+D 也不會消失）。
8. **鎖定、滑鼠穿透、透明 / 毛玻璃、陰影**，右鍵選單裏直接切換。
9. **同一個組件可以放好幾個**，例如三個不同時區的時鐘。
10. **多螢幕、高 DPI**；螢幕配置變了，組件會自動拉回看得見的地方。

### 不寫代碼也能做出自己的風格

11. **控制中心**：左邊選組件，右邊改設定，桌面上的組件同時跟着變。
12. **通用外觀**：背景、透明度、毛玻璃、圓角、字體、字號、文字色、強調色、陰影、內距，每個組件都能改。
13. **自訂資訊卡**：用模板拼內容，例如 `CPU {cpu}% · 記憶體 {mem}% · {time:HH:mm}`。
14. **自訂 CSS 欄位**：給想再進一步的人。
15. **自己畫的右鍵選單**：常用開關直接在選單裏切換，切完選單不關，馬上看到結果；可以全程用鍵盤操作。

### 真的能用的組件（不只是裝飾）

16. **媒體控制**：Spotify、瀏覽器影片、媒體播放器都能控制，封面加進度條，點進度條可以跳。
17. **音量**：按音量鍵、插耳機，組件馬上跟着變；在組件上滾滾輪就能調音量。
18. **番茄鐘、計時器會準時發 Windows 通知**，組件被隱藏也一樣。
19. **使用曲線**：一放上桌面就畫出最近幾分鐘的 CPU 和記憶體。
20. **快捷啟動**：把程式、資料夾、網址拖進去就好。
21. **相框**：選一個資料夾，自動輪播；拍立得樣式很適合「書桌上的紙」。
22. **白噪音**：五種聲音各有一條推桿，自己混。
23. **防誤按**：清空回收筒、關機、重新啟動都要在幾秒內按第二下。

### 輕量

24. **38 種組件全部放上桌面：處理器約 0.4%，記憶體約 355 MB。** 一個組件約 95 MB，之後每多一個約 +4 MB。
25. **玩遊戲、看全螢幕影片時自動暫停**，關掉就回來。
26. **小 zip 約 4 MB**，解壓就能用，不用安裝。
27. **便攜模式**：放一個名為 `portable` 的空檔案，資料就跟着程式走，可以放隨身碟。
28. **低資源模式**：關掉 GPU 加速，記憶體壓得更低。

### 給開發者

29. **一個資料夾就是一個組件**：`widget.json` + HTML/CSS/JS，用任何前端框架都行。
30. **十分鐘寫出第一個組件**：控制中心「新建組件」從範本開始，附繁中、簡中、英文開發文檔。
31. **存檔就重新載入**、F12 開 DevTools、出錯時直接在卡片上顯示錯誤和位置。
32. **TypeScript 型別定義**（`widget.d.ts`）。
33. **`widget.json` 裏寫設定項，控制中心自動產生表單**。
34. **API 很齊**：系統數據、存儲、跨網域請求、通知、音量、媒體、打開程式、選檔案和資料夾。
35. **打包成 `.fwz`，雙擊安裝**；也可以拖進控制中心。

### 安全、乾淨

36. **權限要用戶同意**：組件要連哪個網站、要不要系統數據，安裝時都列出來；更新後多要的權限要再確認。
37. **每個組件互相隔離**，不能直接讀寫檔案、不能彈窗、不能跳到外部網頁。
38. **免費、開源、沒有廣告、不用帳號**。

## 二、視頻規劃

### 做三個版本

| 版本 | 長度 | 比例 | 用在哪 | 給誰看 |
|---|---|---|---|---|
| **主片** | 60–75 秒 | 16:9 | GitHub README、YouTube、B 站、官網 | 所有人 |
| **短片** | 15–20 秒 | 9:16（另出 1:1） | 抖音、小紅書、YouTube Shorts、X | 滑手機的人，只求「好看，想要」 |
| **開發者篇** | 2–3 分鐘 | 16:9 | B 站、YouTube、開發者社群 | 前端開發者 |

先做主片，短片從主片的素材剪。開發者篇之後再做。

### 主片的主軸

**一句話：「好看的桌面，三秒換一套；想要更多，就自己寫。」**

順序跟着三種用戶走：先讓人覺得好看（普通用戶）→ 再讓人覺得能改（中等用戶）→ 最後讓人覺得能寫（開發者）→ 收在「免費、開源、輕量」。

**風格**：不要旁白，用畫面 + 大字字幕 + 音樂節奏切換。字幕短，一句不超過 10 個字。這樣一份畫面就能出繁中、簡中、英文三個字幕版本。

### 短片分鏡（約 18 秒）

| 時間 | 畫面 | 字幕 |
|---|---|---|
| 0–2 秒 | 直接從排滿組件的桌面開始（第一秒就要好看） | Windows 也能這麼好看 |
| 2–8 秒 | 主題連切三次（主片鏡頭 3） | 三套主題，一鍵切換 |

9:16 的畫面：把桌面中間一塊裁出來，組件要擺在桌面中央那一條，拍攝時就要預留。

### 開發者篇（2–3 分鐘，之後做）

1. 控制中心「新建組件」→ 資料夾打開 → 看到 `widget.json`、`index.html`、`main.js`
2. 用 `widget.system.subscribe('cpu', …)` 寫一個 CPU 條，存檔就出現
3. 在 `widget.json` 加一個設定項 → 控制中心自動長出表單
4. 用 `--w-*` 變數 → 切主題時自己的組件也跟着變
5. 故意寫錯一行 → 卡片上顯示錯誤，點一下打開 DevTools
6. 匯出 `.fwz` → 另一台電腦雙擊安裝 → 權限確認
7. 收尾：開發文檔網址、GitHub、（如果線上組件庫做好了）「投稿到組件庫」

## 三、音樂、字幕、封面

- **音樂**：輕快的電子或 lo-fi，BPM 110–125，主題切換對準重拍。用 YouTube 音訊庫、Pixabay Music 這類可商用、免標註或標註即可的曲子，記下授權來源。
- **字幕**：大字、置中偏下，粗體無襯線（Segoe UI Variable / 思源黑體），白字加淡陰影；一個鏡頭一句。
- **封面 / 縮圖**：三套主題並排（同一佈局切成三塊斜切），上面一行大字「Windows 桌面小組件・免費開源」。
- **標題範例**：
  - 繁中：「38 個免費桌面小組件，三秒換一套風格｜FullWidget」
  - 簡中：「免费开源的 Windows 桌面小组件，38 个组件三种风格」
  - 英文：「38 free desktop widgets for Windows — switch styles in one click」

## 四、拍攝準備

### 環境

- [ ] 用一個乾淨的 Windows 帳號或測試資料夾（`--data-dir=` 指到新資料夾），不要用自己的日常設定。
- [ ] 隱藏桌面圖示、工作列設為自動隱藏或只留必要圖示；關掉通知（番茄鐘通知的鏡頭除外）。
- [ ] 解析度 2560×1440 或 1920×1080，縮放 100% 或 150% 固定不變；錄 60 fps。
- [ ] 錄影工具：OBS（免費），開「游標高亮」或剪輯時再加。
- [ ] 準備 3 張好看的桌布（每個主題配一張），注意授權（Unsplash 可商用）。

### 畫面裏的內容要能公開

- [ ] **媒體控制**：用自己有權使用的音樂和封面，不要出現真實的歌手和專輯。
- [ ] **相框**：用自己拍的或可商用的照片。
- [ ] **電腦資訊、網路狀態**：會顯示 IP、電腦名稱、開機時間，拍攝前改好或避開。
- [ ] **天氣、世界時鐘**：選有代表性的城市（台北、東京、London、New York）。
- [ ] **便利貼、待辦、習慣打卡**：先填好好看的範例內容。

### 用命令行讓鏡頭可以重拍

程式支援 `--cmd`，可以寫一個腳本，每次都排出同一個佈局、按節奏一個個加上組件，方便重拍和對音樂：

```bash
FullWidget.exe --cmd="add fullwidget.clock"
FullWidget.exe --cmd="move fullwidget.clock 120 100"
FullWidget.exe --cmd="add fullwidget.weather"
FullWidget.exe --cmd="move fullwidget.weather 120 320"
```

切主題用 `--cmd="theme instrument"`（或 `type`、`paper`），主題切換的鏡頭可以用腳本精準對拍。其他命令還有 `size`、`style`、`layer`、`hide-all`、`show-all` 等，見 [M1 完成說明](M1-完成說明.md)。

### 要拍的素材清單（照分鏡）

- [ ] 空桌面 → 組件逐個淡入（每套主題各拍一次）
- [ ] 同一佈局三套主題切換
- [ ] 每個組件的特寫，各 3–5 秒（拍多一點，剪的時候挑）
- [ ] 媒體控制、音量鍵連動
- [ ] 拖動吸附、排列模式
- [ ] 控制中心改外觀，桌面同時變
- [ ] 自訂資訊卡打模板
- [ ] VS Code 改 CSS → 熱重載
- [ ] 雙擊 `.fwz` → 權限對話框 → 出現在桌面
- [ ] 全螢幕程式開關前後
- [ ] 任務管理器：38 個全開時的 CPU 和記憶體
- [ ] Logo 收尾畫面
