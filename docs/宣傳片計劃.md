# 宣傳片計劃 — 60 秒功能巡禮

日期：2026-11-03（取代舊的《宣傳視頻企劃》）

## 要做甚麼

一支 **60 秒、16:9、1920×1080、60fps** 的宣傳片：

- **做法**：整支片是一個 HTML 頁面，在瀏覽器裏播；再逐幀錄成 **MP4**。
- **風格**：跟官網（`site/`）一樣：
  - 暖白底 `#f5f4f0` 和深色段 `#0e1013` 硬切交替。
  - 字體：Segoe UI Variable Display 粗體大標，數字用 Cascadia Mono。
  - 組件放在 logo 四色派生的漸層小桌布上。
  - 薄荷色 `#7de2c4` 是強調色。
- **動效**：像蘋果的宣傳片：
  - 整支片是**一個連續鏡頭**，上一段的東西變成下一段的主角，不用硬切換場。
  - 只有「開源」那一段故意切到深色，和官網一樣。
- **聲音**：先不配樂。轉場和重點都卡在 **120 BPM** 的節拍上（一拍 0.5 秒、一小節 2 秒），你之後配一首 120 BPM 的音樂就會對上。

## 分鏡（30 小節）

| 4–12s | 組件多 | 四格繁殖成官網首屏那種瀑布流，6 欄、各欄速度不同地往下流，鏡頭慢慢推進、微微傾斜。最後鏡頭鑽進其中一格的時鐘。 | **38 個組件。**（時鐘、天氣、系統、效率、媒體，打開就有。） |
| 12–20s | 三套主題 | 那一格放大成一整個桌面，上面五個組件。每兩拍換一套主題：量被畫出來 → 書桌上的紙 → 玻璃上的字。桌布和組件一起換，主題名逐字浮現。 | **三套主題，一鍵換裝。** |

## 蘋果式動效的做法

- **一個鏡頭**：所有東西放在同一個「世界」裏，用一台虛擬攝影機（位置、縮放、輕微 3D 傾斜）在世界裏移動。轉場就是攝影機的移動，加上共用元素的變形。
- **字**：大字一個詞一個詞浮上來，從模糊、半透明、往下 20px 變清楚。緩動用官網的 `--slide`（cubic-bezier(0.22, 1, 0.36, 1)）。
- **吸附、按下、拼合**：用官網的 `--click` 回彈曲線（cubic-bezier(0.3, 1.45, 0.5, 1)），和程式本身一樣。
- **層次**：前景、組件、桌布三層以不同速度移動，製造景深；陰影用官網那種負擴散的柔和陰影。
- **每一幀都只由時間決定**：畫面是時間 t 的純函數，沒有自己跑的動畫和計時器。這樣在瀏覽器裏可以隨意拖時間軸預覽，錄 MP4 時每一幀也都準確、可重現。

## 組件怎麼畫

- **大部分組件**：用官網已有的 2 倍真實渲染圖 `site/assets/widgets/<資料夾>/<主題>.<語言>.webp`（38 個 × 3 主題，透明底）。放在跟官網一樣的漸層小桌布上。
- **要即時變化或放很大的組件**（主題段的時鐘、自己寫的那個組件）：用官網的 `site/widget-host.js` 在 iframe 裏跑真正的組件程式。
  - 時鐘固定顯示 **9:41**，不顯示秒，保證每次錄出來都一樣。
  - 要給 `widget-host.js` 加一個小選項，讓它能在組件裏放入固定的時間。這個改動不影響官網。
- **控制中心「線上」分頁和權限單**：照官網的做法用 HTML 重畫，顏色和控制中心一致。
- **游標**：自己畫的 Windows 11 風格游標，按下時有一圈漣漪。

## 檔案

- `promo/index.html`
  - 打開就播，下方有播放/暫停、時間軸、小節刻度和分段跳轉。
  - 空白鍵暫停，←/→ 跳一拍；`?t=20` 從第 20 秒開始。
  - 錄影時用 `?render`，隱藏所有控制。
- `promo/promo.css`：官網的色彩和字體變數，加上影片用的版面。
- `promo/engine.js`：時間軸核心，包括節拍換算、關鍵幀、緩動曲線和攝影機。
- `promo/scenes.js`：八段分鏡，各自是「時間 → 畫面」的函數。
- `promo/copy.js`：所有字幕。
- `promo/render.mjs`：Node 腳本，不用安裝任何套件：
  1. 開一個本機伺服器。
  2. 用無頭 Edge 逐幀截圖。
  3. 交給 ffmpeg 編成 MP4。
  - 也能 `--stills 6,14,22` 只輸出幾張靜態圖，方便檢查。
- `promo/README.md`：怎麼預覽、怎麼錄，以及每個轉場落在第幾拍（給配樂用）。
- 輸出到 `promo/out/`，不放進 git。

## 需要先準備

- **ffmpeg**：這台電腦沒有。打算從官方推薦的 gyan.dev 下載 Windows「essentials」版（約 100 MB），放在 `D:\Claude\Widget\.tools\ffmpeg\`，不裝到系統裏，也不進 git。**下載前會先問你。**
- **組件市場**：影片會介紹「線上安裝」，但市場倉庫現在還是私人的。影片發佈前要先公開市場；如果還不想公開，這一段改成「打包分享，雙擊 .fwz 安裝」。
- **舊的《宣傳視頻企劃》**：照你說的不用了，會刪掉 `docs/宣傳視頻企劃.md`（git 歷史裏還找得回來）。

## 怎麼驗收

- **靜態圖**：每段抽 2–3 張（共約 20 張），我逐張看構圖、字有沒有被裁、顏色對不對，再拼成一張總覽發給你。
- **連續性**：每 0.25 秒抽一幀拼成縮圖表，確認沒有跳幀、空白幀，以及沒有元素突然出現或消失。
- **可重現**：同一個時間點錄兩次，兩張圖要完全一樣。
- **MP4**：用 ffprobe 確認 1920×1080、60fps、60 秒、3600 幀、H.264。
- **你來看**：MP4 發給你看動效手感。我只能看靜態幀，順不順要你判斷。
- **配樂對照表**：README 列出每個轉場在第幾秒、第幾拍。

## 不做

- 配音和配樂。
- 直版短片：之後要的話，可以用同一套動畫重排。
- 把影片放上官網。
