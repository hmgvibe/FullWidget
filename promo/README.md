# FullWidget 宣傳片

60 秒、16:9、1920×1080、60fps。整支片是一個 HTML 頁面，風格和官網（`site/`）一樣。

## 預覽

畫面要從本機伺服器打開，因為它要讀 `../site` 的組件圖和 `../widgets` 的時鐘組件：

```
node promo/render.mjs --serve
```

然後打開 <http://127.0.0.1:8080/promo/index.html>：

- 下方時間軸可以拖動，刻度是小節，綠線是每一段的開頭。
- 空白鍵播放或暫停，← → 前後跳一拍。
- `?t=20` 從第 20 秒開始，`?pause` 打開時先暫停。

## 錄影

```
node promo/render.mjs                        整支片 → promo/out/FullWidget-promo.mp4
node promo/render.mjs --stills 6,14.5,40     單幀 PNG → promo/out/stills/
node promo/render.mjs --sheet 0:60:0.5       每 0.5 秒一幀的縮圖表 → promo/out/sheet-*.png
node promo/render.mjs --assets               重拍 9:41 的時鐘圖（assets/clock-0941.*.png）
```

- 錄影時用無頭 Edge 逐幀截圖。每一幀只由時間決定，同一個時間點錄幾次都一樣。
- MP4 需要 ffmpeg：放在 `.tools/ffmpeg/bin/ffmpeg.exe`（不進 git），或系統 PATH 上的 ffmpeg。
- 選項：
  - `--workers N`：同時開幾個 Edge。
  - `--from 10 --to 20`：只錄一段。
  - `--fps 30`：改幀率。

## 檔案

| 檔案 | 內容 |
|---|---|
| `index.html`、`main.js` | 頁面和播放控制。`?render` 隱藏控制，給錄影用 |
| `engine.js` | 時間軸核心：節拍、緩動曲線（和官網的 `--slide`、`--click` 一樣）、關鍵幀、逐字浮現 |
| `scenes.js` | 八段分鏡，畫面是時間 t 的函數 |
| `copy.js` | 所有字幕 |
| `promo.css` | 官網的色彩、字體、桌布漸層和卡片樣式 |
| `clock.html` | 讓 `--assets` 拍 9:41 的時鐘 |
| `assets/` | 9:41 的時鐘圖；組件市場兩個組件的 2 倍預覽圖 |

**組件圖從哪來：**

- 大部分是官網的 2 倍真實渲染圖（`site/assets/widgets/`）。
- 桌面上的時鐘是真正的時鐘組件，經官網的 `site/widget-host.js` 在 iframe 裏跑，時間固定在 9:41。

## 改內容

- **改字**：改 `copy.js`。
- **改時間**：在 `scenes.js` 裏，每段的時間寫在各自的函數中（秒數）。改了時間要一起改上面的對照表。
- **改了組件的樣子**：先跑 `node build/make-previews.mjs --scale 2 --out site/assets/widgets` 重拍官網的組件圖，再跑 `--assets` 重拍時鐘。
