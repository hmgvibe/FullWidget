# FullWidget 宣傳片

74 秒、16:9、1920×1080、60fps，快剪的功能巡禮。整支片是一個 HTML 頁面，風格和官網（`site/`）一樣。配樂也是用程式寫的（`music.mjs`）。

## 預覽

```
node promo/render.mjs --serve
```

打開 <http://127.0.0.1:8080/promo/index.html>：

- 下方時間軸可以拖動，刻度是小節，綠線是每一段的開頭。
- 空白鍵播放或暫停，← → 前後跳一拍。
- `?t=20` 從第 20 秒開始，`?pause` 打開時先暫停。
- 畫面裏的組件是真的組件在跑（見下面）。往回拖時它們不會倒退，從頭播放或重新整理就好。

## 錄影

```
node promo/render.mjs --to 74                整支片 → promo/out/FullWidget-promo.mp4
node promo/render.mjs --stills 6,14.5,40     單幀 PNG → promo/out/stills/
node promo/render.mjs --sheet 0:74:0.5       每 0.5 秒一幀的縮圖表 → promo/out/sheet-*.png
node promo/render.mjs --assets               重拍 9:41 的時鐘圖（assets/clock-0941.*.png）
node promo/render.mjs --page livetest.html --stills 0,1,2   檢查真組件在虛擬時鐘上跑不跑得起來
```

- 錄影時用無頭 Edge 逐幀截圖，4 個 Edge 平行錄。
- MP4 需要 ffmpeg：放在 `.tools/ffmpeg/bin/ffmpeg.exe`（不進 git），或系統 PATH 上的 ffmpeg。
- 選項：
  - `--workers N`：同時開幾個 Edge。
  - `--from 10 --to 20`：只錄一段。
  - `--fps 30`：改幀率。
- 這台電腦的 Edge 會自動裝上 AdGuard 擴充，它的歡迎分頁會讓錄影卡住。腳本已經關掉擴充，並自動關掉多出來的分頁。

## 配樂

```
node promo/music.mjs           只做音樂 → promo/out/music.wav
node promo/music.mjs --mux     再和影片合在一起 → promo/out/FullWidget-promo-music.mp4
```

- **原創**：120 BPM、D 大調，走產品功能影片那種風格：緊的鼓、撥弦合成器、會走動的低音、底下一層長音。和弦每小節換一次：Dmaj9 → Bm9 → Gmaj9 → Asus。
- **全部用程式合成**：振盪器、噪音、濾波器和一個小殘響，不用任何取樣，也不裝 npm 套件。每次跑出來都一模一樣。
- **跟着畫面走**：每個切點、點擊、吸附、打勾、打字都有對應的聲音，時間點直接寫在 `music.mjs` 裏，和 `scenes.js` 的時間一致。改了鏡頭的時間，要一起改這裏。
- **段落**：

  | 秒 | 音樂 |
  |---|---|
  | 0–5 | logo 四個音、和弦一拍一下，鼓還沒進 |
  | 5 | 鼓、低音、琶音一起進來 |
  | 39–42 | 全螢幕：整首歌被悶住，像隔着一面牆 |
  | 42–46 | 寫組件：鼓減半，聽得到打字聲 |
  | 59–66 | 深色那段：鼓停，大的長音和慢慢回來的撥弦 |
  | 66–72 | 全部回來，最後一個和弦留着響到結束 |

- **音量**：合成時用柔和削波壓住峰值；`--mux` 再把響度調到 −14 LUFS、峰值不超過 −1 dBTP（線上影片平台的標準）。
- `--mux` 不重新編碼畫面，只把聲音加進去。

## 真組件和虛擬時鐘

時鐘、翻頁時鐘、指針時鐘、番茄鐘、系統監控、使用曲線、網速、待辦、計算機、媒體控制、白噪音這些組件，都是真的組件程式（`widgets/`），經官網的 `site/widget-host.js` 在 iframe 裏跑。

`live.js` 在每個組件裏換掉 `Date`、`setTimeout`、`setInterval` 和 `requestAnimationFrame`：

- **時間由影片推進**：組件的時間跟着影片的時間軸走，所以它們真的在走、在倒數、在重畫，同一幀錄幾次都一樣。
- **可以加速**：每個組件有自己的速度，例如番茄鐘快 90 倍。
- **模擬的數據**：系統數字（CPU、記憶體、網速）和播放中的音樂是編出來的平滑曲線。
- **操作**：打勾、按計算機這類操作，在指定的時間點模擬點擊。

## 檔案

| 檔案 | 內容 |
|---|---|
| `index.html`、`main.js` | 頁面和播放控制。`?render` 隱藏控制，給錄影用 |
| `engine.js` | 時間軸核心：節拍、緩動曲線（和官網的 `--slide`、`--click` 一樣）、關鍵幀、逐字浮現 |
| `live.js` | 真組件的虛擬時鐘和模擬數據 |
| `scenes.js` | 所有鏡頭，畫面是時間 t 的函數 |
| `copy.js` | 所有字幕和文字 |
| `promo.css` | 官網的色彩、字體、桌布漸層和卡片樣式 |
| `music.mjs` | 配樂：合成器、樂譜和音效時間點 |
| `clock.html`、`livetest.html` | 拍 9:41 時鐘圖；檢查真組件 |
| `assets/` | 9:41 的時鐘圖；組件市場兩個組件的 2 倍預覽圖 |

## 改內容

- **改字**：改 `copy.js`。
- **改時間**：每個鏡頭的時間寫在 `scenes.js` 的 `shot(開始, 結束, …)`。改了要一起改上面的表和 `music.mjs` 的音效時間。
- **改了組件的樣子**：先跑 `node build/make-previews.mjs --scale 2 --out site/assets/widgets` 重拍官網的組件圖，再跑 `--assets` 重拍時鐘。
