# {{name}}

This folder is a FullWidget widget.

| File | What it's for |
|---|---|
| widget.json | Name, size, permissions and settings |
| index.html, style.css, main.js | The widget itself, written like a web page |
| icon.svg | Its icon in the gallery and menus |
| widget.d.ts, jsconfig.json | Let VS Code and similar editors suggest `widget.` calls |

In developer mode, save a file and the widget on the desktop reloads; press F12 for the developer tools.

Full guide: Control Center → Settings → Developer guide.
